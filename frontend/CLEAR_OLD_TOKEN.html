🔧 Clear Old Token

⚠️ PERHATIAN: Token lama (format base64 simple) tidak kompatibel dengan sistem baru (JWT). Halaman ini akan membersihkan token lama dan memaksa Anda login ulang dengan token baru.

Masalah yang Akan Diperbaiki:

  • ❌ Auto logout setelah refresh
  • ❌ Error: "Failed to execute 'atob'"
  • ❌ Token validation error
  • ❌ Invalid character error

Checking...
✅ SUCCESS! Token lama berhasil dihapus.

Next Step:
  1. Close all browser tabs
  2. Open new tab
  3. Go to: index.html
  4. Login with new credentials

📝 Technical Details:

Old Token Format (Incompatible):

eyJ1c2VyX2lkIjoxLCJ1c2VybmFtZSI6ImFkbWluIn0=
(Single base64 string, 1 part)

New Token Format (JWT Proper):

eyJhbGci...Header
.
eyJ1c2Vy...Payload
.
dBjftJeZ...Signature
(Three parts separated by dots)

🔐 What This Does:

  • Removes token from localStorage
  • Removes userRole from localStorage
  • Removes username from localStorage
  • Clears all session data
  • Forces fresh login with new JWT token

Manual Method (If button doesn't work):

Open Browser Console (F12) and run:

localStorage.clear();
console.log('✅ All storage cleared');
location.reload();
